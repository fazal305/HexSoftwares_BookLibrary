# 🏋️ IRONPEAK GYM — Fitness Website

A modern, responsive single-page gym website built using **HTML5, CSS3, and Vanilla JavaScript**. This project was developed as **Project 2** for the **HexSoftwares Frontend Development Internship** and later polished as part of the **Fazal Labs** portfolio ecosystem.

# 📖 Overview

IRONPEAK GYM is a responsive fitness website designed to showcase a modern gym's facilities, training programs, membership plans, trainers, testimonials, and contact information.

The project demonstrates responsive web design, JavaScript interactivity, smooth animations, and accessible user interface development without relying on external JavaScript frameworks.

# 🚀 Getting Started

Clone the repository:

```bash

```

Open the project:

```bash
cd HexSoftwares_GymWebsite
```

---

# 🏗 Architecture Notes

The project follows a simple static frontend architecture.

* **index.html** contains the website structure and page sections.
* **styles.css** manages responsive layouts, animations, color variables, typography, and visual styling.
* **script.js** controls counters, pricing toggle, testimonial slider, smooth scrolling, scroll animations, and form validation.
