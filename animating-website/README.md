# HexSoftwares Animating Website 🚀

## Internship Project
This project was built as part of the HexSoftwares Internship Program.

## 📌 Project Description
A fully animated single-page website built using HTML, CSS, and JavaScript.  
It features staggered animations, scroll-triggered effects, a typewriter system, and modern cyberpunk UI design.
## 🔗 Live Demo
https://fazal305.github.io/HexSoftwares_AnimatingWebsite/
---

## ✨ Features

### 🎬 CSS Animations
- @keyframes fadeIn
- slideUp, slideLeft, slideRight
- shimmer text effect
- floating particle animation
- gradient background animation
- pulse glow effects

### ⏳ Animation Delays (Stagger System)
- Navbar links: 0s → 0.5s
- Hero elements: 0.3s → 2.5s
- Skill cards: 0s → 0.5s stagger
- Projects: alternating slide animations

### ⚙️ JavaScript Features
- Typewriter effect (looping roles)
- IntersectionObserver scroll animations
- Navbar glass effect on scroll
- Skill bar animation on scroll
- Back to top button

---

## 🛠️ Tech Stack
- HTML5
- CSS3 (Keyframes Animations)
- Vanilla JavaScript (ES6)
