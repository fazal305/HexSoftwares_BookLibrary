# HexSoftwares Resume Website

A clean, responsive, HTML-only resume website built as part of the HexSoftwares Frontend Development Internship.

## Live Links

- GitHub Repository: https://github.com/fazal305/HexSoftwares_Resume_Website
- Live Demo: https://fazal305.github.io/HexSoftwares_Resume_Website/

## Overview

This project is a personal resume website for Fazal Abbas. It presents profile information, technical skills, soft skills, highlighted projects, and contact links in a simple single-page layout.

The goal of this project was to create a professional online resume using only HTML and internal CSS while keeping the structure readable, accessible, and beginner-friendly.

## Features

- Professional hero section
- Profile photograph
- About Me section
- Technical and soft skills
- Highlighted projects section
- Contact information with working links
- Responsive single-page layout
- Semantic HTML structure
- Print-friendly styling
- No JavaScript or external frameworks

To run this project locally:

Clone the repository.
git clone https://github.com/fazal305/HexSoftwares_Resume_Website.git
Open the project folder.
cd HexSoftwares_Resume_Website
Open index.html in your browser.

No installation, build tools, or dependencies are required.

Architecture Notes

The project uses a single index.html file with internal CSS. The page is divided into clear sections:

Header / hero section
About section
Skills section
Highlighted projects section
Contact section
Footer

This keeps the project lightweight and easy to deploy on GitHub Pages.
